# APEX AI

An intelligent AI-powered chat web application built with React and powered by Groq's ultra-fast LLM API.

## 🎯 Features

- **Real-time AI Responses** - Get instant responses from advanced language models
- **Clean User Interface** - Simple, intuitive chat interface
- **Lightning Fast** - Powered by Groq's fastest inference engine
- **Responsive Design** - Works on desktop and mobile

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **AI Engine:** Groq LLM API
- **Deployment:** Netlify
- **Version Control:** Git
